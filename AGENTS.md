# sta-blog

**Generated:** 2026-07-05

## OVERVIEW

Blog project with 3 sub-projects: a Java/Spring server, a Vue 3 public UI (Element Plus), and a Vue 3 admin panel (Ant Design Vue). The server is being migrated from a legacy `sta-blog-server` to the Ruoyi-based `ruoyi-vue-pro/sta-module-blog`.

## STRUCTURE

```
sta-blog/
├── sta-blog-server/       # Legacy Java/Spring Boot backend (being deprecated)
├── sta-blog-ui/           # Public frontend: Vue 3 + Vite + Pinia + Element Plus
└── sta-blog-ui-admin/     # Admin panel: Vue 3 + Ant Design Vue + Mist CLI
```

## WHERE TO LOOK

| Task | Location | Notes |
|------|----------|-------|
| API client (auto-gen) | `sta-blog-ui/src/api/` | Generated by @umijs/openapi, do not hand-edit |
| Legacy API calls | `sta-blog-ui/src/apis/` | Being migrated to src/api/ |
| UI composables | `sta-blog-ui/src/composables/` | useDemotion, useReadingMode, useSliderVerify |
| Admin pages | `sta-blog-ui-admin/src/pages/` | blog/, system/, account/, etc. |
| Admin API | `sta-blog-ui-admin/src/api/` | Hand-written API calls to backend |
| Server config | `sta-blog-server/src/main/resources/` | application.yml, static assets |

## CONVENTIONS

- sta-blog-ui: Vue 3 + Composition API + Pinia stores + Element Plus
- sta-blog-ui-admin: Vue 3 + Ant Design Vue + Mist CLI toolchain + UnoCSS
- sta-blog-server: Legacy Spring Boot (being replaced)
- sta-blog-ui uses `pnpm`, sta-blog-ui-admin uses `pnpm` + Mist CLI
- OpenAPI codegen: `pnpm openapi` in sta-blog-ui regenerates API client

## ANTI-PATTERNS

- Do not hand-edit sta-blog-ui/src/api/ (auto-generated)
- Do not add new features to sta-blog-server (legacy, migration in progress)
- Dual API layers in sta-blog-ui (src/api/ vs src/apis/) — prefer src/api/
