# DEBUG — Bug 链路归档

> 记录已出 bug 的链路，方便再次精确定位同类问题。
> 每条记录包含：症状、链路（从入口到根因）、根因+修复。
> 按类别分组，Agent 扫读表格快速匹配。

---

## 使用方式

1. 遇到 bug 时，先在对应类别表格中搜索相似**症状**
2. 如果匹配，按**链路**检查相同或相似的代码路径
3. 修复后，在对应表格末尾追加新条目
4. 如果是新类别，添加新的 `## 类别` section
